# Altrium Recruitment Tracker
Our project (Altrium Recruitment Tracker) is built with PHP and MySQL on the backend. GitHub / GitHub Pages only hosts static files (HTML, CSS, JS) — it cannot run PHP or a database, so the site can't work if hosted directly from GitHub. Because of that, I deployed it on InfinityFree, a free web hosting service that supports PHP and MySQL, so the full site (login, database, all features) works properly.

The GitHub repository is only for storing and versioning the source code — the live, working version of the site is hosted separately at:
https://altrium.page.gd/pages/Login.html
